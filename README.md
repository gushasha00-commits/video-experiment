# 视频材料预实验程序

## 文件结构

```
video_experiment/
├── experiment.html      ← 被试端：播放候选视频 + 收集评价
├── analyze.html         ← 主试端：汇总多人数据 + 筛选最优视频
├── videos/
│   ├── 极地海洋.mp4     ← 候选视频 A（~10 min，CC/教育用途）
│   ├── 太阳系.mp4       ← 候选视频 B（~10 min，CC/教育用途）
│   └── 欧洲地形.mp4     ← 候选视频 C（~10 min，CC/教育用途）
├── calc_asl.py          ← 视频镜头节奏分析工具
├── check_taiyangxi.py   ← 太阳系视频阈值调试工具
└── README.md
```

## 视频材料要求

- 时长约 10 分钟
- 中等趣味性（预测试评分 4–5/7）
- 中等信息密度
- 无需专业知识即可理解
- 公开可获取（CC 协议或教育用途允许）

## 线上部署说明

要让远程被试通过链接访问，需要：

1. **托管视频文件**：将 `videos/` 目录下的 MP4 文件上传至可公网访问的存储服务（如阿里云 OSS、腾讯云 COS、GitHub Releases 等），获取各视频的公网 URL。

2. **修改视频 URL**：打开 `experiment.html`，在顶部 `CONFIGURATION` 区域将 `VIDEO_BASE` 或各视频的 `src` 替换为实际的公网地址。

3. **托管 HTML 页面**：将 `experiment.html` 部署到任意静态托管服务（GitHub Pages、Netlify、Vercel 等），把生成的链接发给被试即可。

## 预实验流程（experiment.html）

### 每名被试操作

1. 打开 experiment.html 链接
2. 页面自动分配参与者编号
3. 点击「开始观看」
4. 依次观看 3 段候选视频（播放顺序随机平衡，1.0x 原速）
5. 视频播放不可快进/快退/跳转，仅可暂停
6. 每段视频结束后点击按钮进入评价
7. 每段视频评价 6 个维度：
   - **是否看过**：没有看过 / 看过
   - **趣味性**：1（非常无聊）— 7（非常有趣）
   - **信息密度感知**：1（信息量非常低）— 7（信息量非常高）
   - **视频难度**：1（非常容易）— 7（非常困难）
   - **先前知识熟悉度**：1（完全不了解）— 7（非常了解）
   - **主观理解度**：0（完全没有理解）— 100（完全理解）
8. 全部完成后导出数据文件发送给主试

### 主试汇总（analyze.html）

1. 收集全部 20 名被试的数据文件
2. 打开 `analyze.html`
3. 拖拽全部数据文件到上传区
4. 系统自动计算各视频各维度的 M ± SD，按筛选标准判定
5. 生成散点图（趣味性 × 信息密度）
6. 导出汇总统计表

## 预实验筛选标准

1. **看过比例**：排除曾被超过 20% 被试看过的视频
2. **趣味性**：均值在 3.5 – 5.0 之间（中等趣味水平）
3. **信息密度**：均值在 3.5 – 5.0 之间（中等信息密度）
4. **视频难度**：均值在 3.0 – 5.0 之间（中等难度）
5. **先前知识**：均值低于 3.0（若高于 3.5 则排除）
6. **主观理解度**：均值不低于 70 分

最终结果以表格呈现各候选视频在各评价维度上的均值和标准差，据此选出最优材料。
符合多个视频时按评分一致性（平均 SD）排序推荐首选。
